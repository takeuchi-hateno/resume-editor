# 職務経歴書 PDF生成ツール

ブラウザだけで職務経歴書を作成し、A4レイアウトを確認してPDF保存できるビルド不要の静的アプリです。入力内容は外部へ送信しません。

## スクリーンショット

公開時にここへスクリーンショットを追加してください。

## 主な機能

- 左側の入力と右側のA4プレビューを同時表示
- スマートフォンでは「入力」「プレビュー」タブに切替
- LocalStorageへの軽い遅延付き自動保存と保存状態表示
- 匿名サンプル、空の新規作成、JSONの読み込み・書き出し
- JSONの直接編集、既存形式からの移行、読み込み前バックアップ、元に戻す
- 会社・案件・個人開発・自己PRの追加、削除、複製、並べ替え
- セクション表示切替、折りたたみ状態の保存、textarea自動伸長
- 標準・コンパクトの印刷密度、推定ページ数、レイアウト警告
- ブラウザ標準印刷によるA4 PDF保存

## 利用方法

1. 「空の職務経歴書を作る」または「サンプルで試す」を選択します。
2. 入力欄を編集するとプレビューへ反映され、LocalStorageへ保存されます。
3. 別の端末へ移す場合は、JSONを書き出して安全な場所で管理します。
4. 「JSON読み込み」からバックアップを復元します。

JSONには氏名・会社名などの個人情報が含まれる可能性があります。書き出したJSONやPDFをGitへ追加したり、公開リポジトリへアップロードしたりしないでください。アプリはサーバー、外部API、アクセス解析、外部CDN、外部フォントを使用しません。

## PDF保存方法

「PDF出力 / 印刷」を押し、ブラウザの印刷画面で用紙サイズをA4、保存先を「PDFに保存」にして保存します。印刷前に最新の入力をLocalStorageへ保存します。

## JSONバックアップ・復元

書き出しファイル名は `resume-data_YYYY-MM-DD.private.json` です。氏名はファイル名に含めませんが、ファイル内容には個人情報が含まれる可能性があります。1MBを超えるJSONは読み込めません。

不正なJSONや新しい未対応スキーマは現在の入力を変更せずに拒否します。読み込み・初期化・JSON直接反映の前には、直前の状態をブラウザ内バックアップへ保存します。

## 保存とプライバシー

- データはブラウザのLocalStorageにのみ保存され、サーバーへ送信されません。
- LocalStorageは端末・ブラウザ単位で、別PC・別ブラウザへ自動同期されません。
- ブラウザデータを削除した場合、アプリからは復元できません。
- シークレットモード、容量不足、ブラウザ設定によって保存できない場合があります。
- 個人情報を含むJSON・PDFはGitの管理対象にしないでください。

## 開発方法

ビルドや依存関係のインストールは不要です。ローカルHTTPサーバーで確認してください。

```sh
python3 -m http.server 8000
```

ブラウザで [http://localhost:8000](http://localhost:8000) を開きます。`file://` で開くこともできますが、ブラウザのセキュリティ設定によりLocalStorageや印刷の挙動が異なる場合があります。

## Gitフックとローカル監査

公開したくない氏名・会社名・サービス名などをローカルだけのファイルへ登録します。ファイル編集にはviまたはvimを使います。

```sh
vi .private-terms.local
```

編集内容:

- `i`キーで入力開始
- 氏名・会社名などを1行ずつ記載
- `Esc`
- `:wq`
- `Enter`で保存終了

その後、フックを導入します。

```sh
bash scripts/install-git-hooks.sh
```

フックはステージ済みファイルに、`private/`、`*.private.json`、PDF、登録した非公開語が含まれていないか確認します。これは補助的な防止策であり、CIやフックだけで個人情報流出を完全には防げません。公開前に`git status`、`git ls-files`、Git履歴、ソース全文のローカル監査を必ず行ってください。

## GitHub Pages公開方法

1. 公開前の個人情報監査とブラウザ操作テストを完了します。
2. GitHubでPages用の公開リポジトリを作成します。
3. `main`ブランチのルートを「Deploy from a branch」に設定します。
4. HTTPSで公開されることを確認します。
5. 公開URLをこのREADMEへ反映します。

承認前に公開リポジトリ作成・push・Pages有効化を行わないでください。mainへのforce pushやbranch deletionは行わず、Collaborator・Wiki設定も確認してください。

## 既知の制約

- PDFの改ページはブラウザの印刷エンジンに依存します。
- 推定ページ数と実際のページ数はブラウザや印刷設定で差が出る場合があります。
- LocalStorageの容量や利用可否はブラウザごとに異なります。
- 公開前の個人情報監査は必要であり、アプリの自動チェックだけで完全な検出は保証できません。
